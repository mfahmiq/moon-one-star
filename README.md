# The Moon Gets One Star

Entry for the make.fun competition [The Moon Gets One Star](https://make.fun/c/u-eager-stork-81-9647-the-moon-gets-one-star-768236e5): the funniest one-star review of the Moon in 120 characters or fewer.

> One star. It follows me home every night and pretends that's romantic. It's not. It's stalking.

## How it was chosen

Sixteen candidate lines were written from different angles (stalking, phases, reflected sunlight, tides, werewolves, the dark side, orbital speed, night-shift work, and more), then run through an internal pairwise tournament judged against the published judge brief in weight order: on-subject Moon complaint first, then funnier/quicker laugh, then reads like a real one-star review, then a specific surprising grievance (no craters/cheese/brightness jokes), then economy of characters. The champion beat the werewolf line in the final on a quicker first-read laugh, a perfect "One star." review opening, and a more surprising grievance.

## How to run

```sh
python3 main.py
```

This writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), byte-for-byte identical to `entry.txt` in this repository.
